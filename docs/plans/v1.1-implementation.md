## Accepted refinements

- Each profile owns its collections, progress, creations, and future world. Stable profile IDs survive renaming. Guests are saved avatar profiles; no automatic merging or profile eviction.
- Stars describe attainable round accomplishments, never personal records. One for finishing, two for five pops, three for ten pops. The eight-pop introductory round awards three. No empty star slots. Numbers are initial tuning settings.
- Bubble Bay exposes counting through a jar of ten but does not estimate counting knowledge. Future learning games measure content separately from motor control.
- Reading is never required for navigation. Letters, lowercase and uppercase, and words are permitted learning material. Voice clips belong with future deliberate literacy games. No voice production or future game implementation in this pass.
- Keys pop a visibly selected available bubble regardless of pointer location. Arrow keys navigate menus; activation works with a default selection. Enter or the play arrow commits a name; Space only reacts.
- Sticker choices show the actual stickers. Awards use the current page without replacement. A last remaining sticker is offered alone. A completed collection becomes freely playable and arrangeable, without endless upgrades. Optional rewardsEnabled configuration is explicit.
- Worlds may have different media and palettes with consistent navigation. Generated still assets may animate through reviewed parts or frames. Palette snapping is optional.
- No forced difficulty drop every session. Rise only after two qualifying rounds; soften after struggle. Define eligible spawns, recycling, assisted pops and idle exclusions. No in-round tier changes.
- Performance checks include delivered frame intervals and update/render work. Effects must remain readable in aggregate. No screen shake or hit-stop. Full normal animation runs under either browser or operating-system motion preference (owner amendment, 2026-10-02).

## Shared contracts (writers coordinate changes here)

- AppServices.config: uiScale:number, masterTrimDb:number, keyboardLayout:'abc'|'qwerty', profiles:{name:string,aliases?:string[]}[], playtestLog:false, rewardsEnabled:boolean, breakAfterSeconds:number.
- AppServices.debug: enabled:boolean, tier?:0|1|2, seed:number, timeScale:number. AppServices.random():number is seeded in debug, otherwise Math.random.
- AppServices.roundBoundary():void invokes the boot onRoundBoundary callback, for a pending nudge after a celebration. Game calls once upon entering its still rest state. BootOptions.onRoundBoundary is optional.
- Save Profile adds id:string, avatar:string, accent:string, aliases?:string[], unnamed?:boolean; existing name and games remain. getProfile/selectProfile accept ID or normalized name. createGuestProfile() returns and selects a persistent unnamed profile. renameProfile(id,name) preserves identity and returns boolean; exact collisions fail. readOnly/status expose unavailable or protected storage.
- avatarFor/avatarPath/avatarSpriteName/accentFor accept string or Profile; existing strings remain compatible but profile callers use stored identity.
- Input.pointer adds previousX, previousY; input.endFrame() advances previous coordinates after each update. Input suppresses held repeats for both key events. Scenes use swept segments for fast pointer movement.
- Scene navigation must guard against the same physical input activating a new screen. Award choices save immediately and complete exactly once.
